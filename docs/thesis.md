# Agent memory in two years

Production memory will become a set of revocable claims, rather than an ever-growing transcript.

Every useful claim will need an owner, source, purpose, freshness window and correction path. Confidence will describe the evidence supporting a claim, not how fluently a model repeats it. Contradictions will become first-class events: an agent should often ask one good question instead of retrieving more text.

Retrieval will produce a context contract. That contract will state which claims are usable now, which are withheld, why they are withheld and which decisions remain unsupported. Models may explain the contract, but they should not quietly expand its permissions.

Forgetting will be measured across derived artifacts. Removing a row is insufficient if cached summaries, embeddings or downstream assistants can still resurrect it. Systems will need invalidation boundaries and honest disclosure of copies they cannot recall.

The strongest memory products will remember less with better provenance. They will make correction and revocation ordinary user controls, and treat uncertainty as a useful response rather than a defect to hide.
