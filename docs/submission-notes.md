Recollect is a memory layer that knows when to ask. Every claim has a source, reported confidence, freshness window, workspace and person. Retrieval selects the exact scope before answering and shows its evidence. Conflicting current values cause clarification; stale, weak or revoked claims are withheld.

Try Maya / Cedar Studio: add the conflicting entrance update to see “I might be wrong,” confirm the courtyard source, advance 14 days to expire it, then forget the workspace and reload. Personal preferences remain isolated. The privacy receipt contains no remembered values or sources.

Real storage is browser IndexedDB with transactional revision checks and cross-tab invalidation. Forgotten and superseded workspace values are removed from the current vault and exports. The public demo sends no notebook data to the host. Prior exports, backups and provider logs cannot be recalled.

AI tools: OpenAI Codex for implementation and review; genuine DeepSeek v4 Flash for four verified local cases using fictional facts (1739 reported tokens). It answered supported memory, clarified a contradiction and abstained after expiry and revocation. The public demo is deterministic; optional live inference is local and explicit. No provider key is deployed. Confidence is declared support with age decay, not calibrated probability. No external actions or multi-user cloud sync.
