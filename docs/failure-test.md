# Deliberate failure and containment

The client brief says North entrance. A newer, equally confident coordinator says Courtyard entrance. A latest-write-wins assistant would silently pick the new value; a similarity retriever could return either. Recollect retains both sources and supplies no entrance in the answer or model context. It asks for confirmation.

Confirming the courtyard version is a deliberate owner decision. The old version becomes superseded, not silently deleted. Forgetting the workspace then removes both versions, including their source names and quotes, from serialized storage. The content-free receipt cannot recreate either version. Reload must continue to show missing memory; the sample is not reseeded over a nonempty revoked vault.

Further tests cover exact expiry, confidence decay, stale conflicting evidence, scope and subject isolation, prototype-named fields, wrong citations, invented values, invalid model authority, repeated revocation, serialization recovery, body limits, local-origin enforcement, hourly model allowance and safe provider errors. Four actual DeepSeek calls verified supported, conflicting, expired and revoked cases separately from mocked transport tests.

Browser checks must additionally establish IndexedDB persistence across reload, conflict visibility, explicit correction, stale-memory abstention, content-free privacy receipts and preservation of the Personal workspace. Manual deletion cannot revoke an already exported copy or an already transmitted provider prompt; that limit is explicit in the README.
